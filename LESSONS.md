# Lessons for KOML

The domain needs an explicit abstention path: a reply can contain both interest and an objection, and opt-out language needs priority. Transparent match evidence makes those decisions inspectable.

The validated assumption is narrow: a deterministic rule engine can reconcile 200 deliberately planted phrase cases exactly. The fixture contains repeated templates, so it does not validate general reply understanding, demand, revenue or real-world accuracy. Real-language negation and quoted threads remain failure risks.

Operating rule: always compare text-derived outputs with independently supplied labels, test corruption of those labels, and separate synthetic rule coverage from real trial evidence before expanding a build.
